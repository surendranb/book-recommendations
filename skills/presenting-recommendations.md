# Presenting recommendations

## The blind-date two-beat (blind_date picks)

1. **The hook, first**: the first sentence + subjects + era — "a book from
   1962 that opens with 'The lighthouse kept its own counsel…'". Let the
   user guess if they want to.
2. **The reveal**: title, author, links, read_now.

## Regular recommendations (recommend picks)

Title, author, year, one line from its subjects, then links. why_picked
verbatim. Rating when present (OpenLibrary averages — caveat small samples
by mentioning 'reader rating').

## Cross-cutting rules

- Offer read_now links prominently — instant reading beats a shopping link.
- free_classics when the user says "I want to start reading RIGHT NOW".
- A rejected pick goes into the exclude list next spin, not into a re-roll
  of the same query.
